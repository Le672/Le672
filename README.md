## 🚀 精选项目 / Selected projects / 主なプロジェクト

### 🚆 [Yukino Rail Watch](https://github.com/Le672/yukino-rail-watch)

12306 余票查询与提醒，支持车次 / 区间查询、车型插图、下一停靠站、地图与 GPS 定位测速；覆盖网页、Windows 与手机预览。  
12306 ticket availability and alerts, with train / route search, train illustrations, next-stop information, maps, and GPS location and speed; available on the web, Windows, and mobile previews.  
12306 の空席検索・通知ツール。列車番号・区間検索、車両イラスト、次の停車駅、地図、GPS 位置・速度表示に対応。Web、Windows、モバイルプレビューを提供。

[在线使用 · Open app · Web 版](https://cr.yukino.bond) · [下载 · Downloads · ダウンロード](https://github.com/Le672/yukino-rail-watch/releases)

Yukino 的个人数字花园：博客、笔记、全站搜索与常用工具入口，新增邮箱账号登录和设备清单管理。  
Yukino's personal digital garden, with a blog, notes, site-wide search, tool links, mailbox account sign-in, and equipment list management.  
ブログ、ノート、サイト内検索、ツールへの入口をまとめた Yukino のデジタルガーデン。メールアカウントでのログインと機材リスト管理も追加。

[访问 · Visit · サイトへ](https://www.yukino.bond)

Apple Music、NetEase Cloud Music、QQ Music、Kugou、Kuwo、Spotify を横断して歌詞を検索する Salt Player for Windows プラグイン。
